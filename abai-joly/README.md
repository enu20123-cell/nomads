# Абай жолы

Веб-приложение для школьников 9–16 лет: помогает читать казахскую литературу с подсказками и расширять казахский словарь.
Трек Smart Nomad '26: **Qazaq Identity**.

## Что умеет прототип
- **Шың** — путь из 6 ступеней от коротких стихов к романам; ступени открываются по рейтингу чтения.
- **Авторлар** — 10 авторов по 5 произведений (в прототипе готовы 4 произведения).
- **Экран чтения** — объяснение слова по нажатию, смысл строки («?»), режим «Жеңілдет» (упрощённый пересказ).
- **Тапсырма** — вопросы и ответ своими словами; рейтинг пересчитывается по формуле Эло.
- **Сабақ** — ежедневный урок, серия дней, заморозка серии.
- **Профиль** — рейтинг, звания от Шәкірт до Хакім, личный словарь.
- Талисман — Абай Құнанбайұлы с цитатами.

## Запуск
Сборка не нужна. Откройте `index.html` в браузере
или запустите локальный сервер: `python3 -m http.server 8000` и откройте http://localhost:8000.

## Стек
Один файл HTML + CSS + JavaScript, без зависимостей. Прогресс хранится в localStorage браузера.
